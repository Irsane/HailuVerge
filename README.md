# HailuVerge

Простой и современный десктоп-клиент для прокси (по духу близок к **Happ** и **Clash Verge**).
Вставляете ссылку на подписку — приложение само разбирает серверы, проверяет пинг и
подключается к лучшему. Построен на **Electron** + ядро **sing-box**.

![HailuVerge](assets/icon.png)

## Возможности

- 🔗 **Подписки и ссылки** — вставьте `https://auth.example.ru/XXXX` или прямую ссылку
  `vless://`, `hysteria2://`, `trojan://`, `ss://`.
- 🧩 **Протоколы** — VLESS (TCP/WS/gRPC, TLS/Reality), Hysteria и Hysteria2, Trojan,
  Shadowsocks. Транспорт **TCP/UDP** и мультиплексирование **XUDP** для VLESS.
- ⚡ **Авто-подключение к лучшему пингу** — при запуске выбирается самый быстрый сервер,
  **российские серверы пропускаются** при авто-выборе.
- 🌐 **Выбор серверов** — список с пингом, бейджами протокола и пометкой RU.
- 🧭 **Маршрутизация прокси/напрямую** — редактируемые списки доменов: что гнать через
  прокси, а что напрямую (госуслуги, банки и т.д.). Режим «по правилам» или «глобально».
- 🛡 **Блокировка рекламы** — опциональный фильтр рекламных доменов.
- 🎯 **Прокси только для выбранных приложений** — режим TUN с маршрутизацией по именам
  процессов (например, только `chrome.exe` и `telegram.exe`).
- 🖥 **Системный прокси** — авто-настройка для Windows / macOS / Linux (GNOME).
- 📦 **Трей** — сворачивание в трей, быстрое подключение/отключение.

## Установка

```bash
npm install        # зависимости
npm run core       # скачать ядро sing-box для вашей ОС
npm start          # запустить приложение
```

> Ядро sing-box не входит в репозиторий. `npm run core` скачивает официальный бинарник
> в папку `core/`. Можно также указать путь к собственному бинарнику в Настройках.

## Сборка инсталлятора

```bash
npm run build:win     # Windows (.exe / NSIS)
npm run build:mac     # macOS (.dmg)
npm run build:linux   # Linux (AppImage)
```

## Как это работает

```
Подписка (URL) ──► subscription.js ──► список серверов
                                          │
ping.js (TCP latency) ◄───────────────────┘
   │  выбор лучшего (кроме RU)
   ▼
singbox-config.js ──► JSON-конфиг ──► core.js (spawn sing-box)
                                          │
                          system-proxy.js (Win/macOS/Linux)
```

- **`src/main/`** — процесс Electron: парсинг подписок, измерение пинга, генерация
  конфига sing-box, управление процессом ядра и системным прокси.
- **`src/renderer/`** — современный UI (Главная, Серверы, Маршрутизация, Настройки, Логи).

## Структура

| Файл | Назначение |
|------|-----------|
| `src/main/main.js` | Окно, трей, IPC, авто-подключение к лучшему серверу |
| `src/main/subscription.js` | Загрузка подписок, парсинг VLESS/Hysteria/Trojan/SS |
| `src/main/ping.js` | Измерение задержки (TCP-connect) |
| `src/main/singbox-config.js` | Генерация конфигурации sing-box + правила маршрутизации |
| `src/main/core.js` | Жизненный цикл ядра sing-box |
| `src/main/system-proxy.js` | Включение/выключение системного прокси |
| `src/main/store.js` | Хранение настроек (JSON) |
| `src/renderer/*` | Интерфейс |

## Заметки

- Маршрутизация по доменам и пропуск РФ-трафика используют правила и `rule_set` sing-box
  (geosite/geoip), скачиваемые ядром при подключении.
- Режим «прокси только для выбранных приложений» требует TUN и прав администратора —
  без TUN маршрутизация по процессам в системных прокси невозможна.
